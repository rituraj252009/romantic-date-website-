# romantic-date-website-

A romantic 3D date proposal website for Asmita ❤️ featuring cinematic animations, heartfelt Hinglish shayari, floating hearts, a playful interactive proposal, a magical YES celebration, and a personalized date planner. Built with React, Three.js, Lucide Icons, and Tailwind CSS. 🌹

---

## ✨ Features

- 🌌 **Cinematic 3D Romantic Atmosphere**: Interactive Three.js canvas with twinkling starfield, floating glowing 3D hearts, and dynamic mouse parallax effects.
- 💌 **Heartfelt Hinglish Shayari & Love Notes**: Thoughtfully crafted love letters, memories, and reasons why she's special.
- 💍 **Interactive "Will You Go on a Date With Me?" Proposal**:
  - Playful dodging "No" button that playfully moves away when hovered or clicked.
  - Grand celebration modal upon clicking "Yes" with confetti burst and romantic animations.
- 📅 **Personalized Date Planner**: Interactive date activity selector, preferred timing, and custom date itinerary generator.
- 🎵 **Romantic Background Music Player**: Ambient romantic audio track with controls to play/pause anytime.
- 📱 **Fully Responsive & Mobile Optimized**: Beautiful, smooth experience on phones, tablets, and desktops.

---

## 🛠️ Tech Stack

- **React 19**
- **TypeScript**
- **Vite**
- **Three.js** (for 3D hearts & space atmosphere)
- **Canvas Confetti** (for romantic celebration effects)
- **Tailwind CSS** (for styling & glassmorphism)
- **Lucide React** (for modern iconography)

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/rituraj252009/romantic-date-website-.git
   cd romantic-date-website-
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
